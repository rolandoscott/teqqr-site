Turn 1 · code-flavoured marks

Code-flavoured marks

  • 1a <teqqr />
    <teqqr /> </>

    Self-closing tag

    Reads as markup. Very clear it's a web shop. Common idea, but clean.

  • 1b ❯teqqr
    ❯teqqr ❯_

    Terminal prompt

    Prompt + blinking block cursor. Feels hands-on, "I'm the one typing". Cursor can blink in the header.

  • 1c te{qq}r
    te{qq}r {q}

    Braced core

    Keeps your accented "qq" but wraps it in braces, like a template variable. Most ownable of the set.

  • 1d -old.host +teqqr
    +teqqr +

    Diff line

    The migration story as a git diff. Big version for hero/social; compact "+ teqqr" for the header.

  • 1e teqqr();
    teqqr(); t()

    Function call

    "Call teqqr and it runs." Short, playful, reads well small.

  • 1f >_ teqqr
    >_ teqqr >_

    Shell glyph + wordmark

    Separate icon and name, the most conventional lockup. Easiest favicon and social avatar.
